# Google G

`google-g.png`: Google product icon, official source https://www.gstatic.com/images/branding/product/1x/googleg_48dp.png (48 × 48 px). Included inline for offline receipt printing; rendered monochrome by the receipt stylesheet. The website uses the same official asset in color.

# Mercado Pago

`mercadopago.svg`: símbolo oficial sin modificar, fuente https://http2.mlstatic.com/frontend-assets/dx-template-lib/assets/logo-mercadopago.svg (32 × 32). La misma copia se incorpora en `src/ui/payment-choice.js` para que la app y la tienda no dependan de una descarga externa al mostrar los medios de pago.
